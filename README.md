# RoleFit — Skill Mapping & Career Guidance

RoleFit is a student-focused prototype to explore strengths, identify skill gaps, and plan career learning steps.

## Features
- Responsive student dashboard
- Self-rating assessment (technical skills, problem solving, communication, teamwork)
- Sample role-fit score for Frontend Developer, Python Developer, and Data Analyst
- Skill-gap learning suggestions
- Runs locally in a browser; no server or account required

## Tech stack
HTML5, CSS3, vanilla JavaScript.

**Scope note:** The SIH concept also proposed Python, React/Node.js, MongoDB, cloud services, and AI APIs for a future full-stack version. This starter repo is a front-end prototype, not a deployed backend or trained AI model.

## Run locally
Open `index.html` in a browser, or use VS Code Live Server.

## Responsible use
Scores are illustrative only. Do not use them as the sole basis for hiring, admissions, or other high-impact decisions. Do not enter sensitive personal information.
